MOON PHASE API

GET https://randomapi.dev/api/moon/phase?tz=Asia/Shanghai — free, no key. Returns JSON; the site uses data.ageDays (lunar age in days, CST). The moon sprite holds 24 frames in lunar-age order (new → full → new), 3 rows × 8 columns. Frame = floor(ageDays / 29.53 × 24), clamped to 0–23. If the request fails, the default frame stays. Rotation stays random; brightness and moonrise/set times are not used.
